# Licensing

This repository contains MAME 0.106-derived source plus Amiga-specific and
third-party source.

- `MAME-0.106-LICENSE.txt` is the exact `docs/license.txt` from the official
  `mamedev/historic-mame` tag `mame0106`.
- `AMIGA-FRONTEND-LICENSE.txt` preserves the project's existing root `LICENSE`.
- `ZLIB-BUNDLED-LICENSE-NOTICE.txt` preserves the bundled zlib notice.

Existing file-level copyright and licence notices remain in place.

This repository contains source code only. ROMs, CHDs and game data are not
included by the publication script.
